Mode d’emploi

iPhone

  1. Sur l’écran d’accueil, maintenez l’icône de Pense-bête et choisissez une taille de widget (iOS 18 ou ultérieur).
  2. Si aucune taille n’apparaît, maintenez une zone vide, puis utilisez « + » ou Modifier → Ajouter un widget pour ajouter Pense-bête.
  3. La note choisie dans l’app s’affiche. Pour choisir une autre note pour un widget, maintenez-le et ouvrez Modifier le widget.

Android

  1. Ouvrez une note et touchez Ajouter à l’accueil.
  2. Confirmez l’ajout sur votre appareil. La note est déjà sélectionnée.
  3. Si votre appareil ne le permet pas, maintenez l’écran d’accueil et ajoutez Pense-bête depuis Widgets. Maintenez le widget pour le redimensionner.

Placez-le une seule fois

Placez le widget où vous le souhaitez une fois. Modifier la même note actualise son texte, sans devoir l’ajouter à nouveau. Maintenez-le appuyé seulement pour le déplacer.

Aussi sur l’écran verrouillé

iPhone

Maintenez l’écran verrouillé appuyé, choisissez Personnaliser → Écran verrouillé, puis Ajouter des widgets → Pense-bête. Le rectangle affiche quelques lignes, le cercle une note courte et la zone au-dessus de l’horloge une ligne. Touchez un widget pendant la personnalisation pour choisir sa note. Placez-le une seule fois.

Android

Sur les appareils et versions compatibles avec les widgets d’écran verrouillé, ajoutez Pense-bête dans les réglages de verrouillage de l’appareil. La configuration et l’emplacement dépendent de l’appareil. Sinon, utilisez le widget d’accueil.

Choisissez ce que les autres peuvent voir

Les personnes qui regardent votre écran peuvent lire les notes du widget. Ne choisissez pas de mots de passe ni d’informations privées. La visibilité pendant le verrouillage suit aussi les réglages de confidentialité de l’appareil.

Touchez-le pour ouvrir l’éditeur de cette note.

Peut-on supprimer des notes ?

La restauration est possible pendant 30 jours. Une suppression définitive est irréversible.

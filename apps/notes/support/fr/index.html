Mode d’emploi

iPhone

  1. Sur l’écran d’accueil, maintenez l’icône de Pense-bête et choisissez une taille de widget (iOS 18 ou ultérieur).
  2. Si aucune taille n’apparaît, maintenez une zone vide, puis utilisez « + » ou Modifier → Ajouter un widget pour ajouter Pense-bête.
  3. La note choisie dans l’app s’affiche. Pour choisir une autre note pour un widget, maintenez-le et ouvrez Modifier le widget.

Android

  1. Ouvrez une note et touchez Ajouter à l’accueil.
  2. Confirmez l’ajout sur votre appareil. La note est déjà sélectionnée.
  3. Si votre appareil ne le permet pas, maintenez l’écran d’accueil et ajoutez Pense-bête depuis Widgets. Maintenez le widget pour le redimensionner.

Emplacement

Maintenez le widget ajouté et faites-le glisser où vous voulez, par exemple en haut à gauche de la première page. Déplacez les icônes s’il manque de place. L’app ne peut pas choisir la page ou l’emplacement depuis ses réglages.

Questions fréquentes

Faut-il un compte ?

Aucune inscription n’est nécessaire. Pas de synchronisation cloud propre.

Peut-on écrire dans le widget ?

Touchez-le pour ouvrir l’éditeur de cette note.

Peut-on supprimer des notes ?

La restauration est possible pendant 30 jours. Une suppression définitive est irréversible.

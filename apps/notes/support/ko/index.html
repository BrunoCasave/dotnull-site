사용 방법

iPhone

  1. 홈 화면에서 잊지마 메모 아이콘을 길게 누른 뒤 위젯 크기를 선택하세요(iOS 18 이상).
  2. 크기가 보이지 않으면 빈 공간을 길게 누르고 “+” 또는 편집 → 위젯 추가에서 잊지마 메모를 추가하세요.
  3. 앱에서 선택한 메모가 표시됩니다. 위젯 하나에 다른 메모를 지정하려면 위젯을 길게 누르고 위젯 편집을 여세요.

Android

  1. 메모를 열고 홈 화면에 추가를 누르세요.
  2. 기기의 확인 화면에서 추가하세요. 메모를 다시 선택할 필요가 없습니다.
  3. 지원하지 않는 기기는 홈 화면을 길게 누르고 위젯에서 잊지마 메모를 추가하세요. 길게 눌러 크기를 바꿀 수 있습니다.

처음에 한 번만 배치

처음에 원하는 위치에 위젯을 놓으면 같은 메모를 수정할 때마다 표시가 업데이트됩니다. 매번 다시 추가할 필요는 없습니다. 위치를 바꿀 때만 길게 눌러 이동하세요.

잠금 화면에도 표시

iPhone

잠금 화면을 길게 누르고 사용자화 → 잠금 화면 → 위젯 추가에서 잊지마 메모를 선택하세요. 직사각형은 여러 줄, 원형은 짧은 메모, 시계 위에는 한 줄이 표시됩니다. 사용자화 중 위젯을 누르면 메모를 선택할 수 있습니다. 배치는 처음 한 번이면 됩니다.

Android

잠금 화면 위젯을 지원하는 OS와 기기에서는 잠금 화면 설정에서 잊지마 메모를 추가할 수 있습니다. 추가 방법과 위치는 기기에 따라 다릅니다. 미지원 기기에서는 홈 화면 위젯을 이용하세요.

표시할 메모를 신중하게 선택

화면을 보는 다른 사람도 위젯 메모를 읽을 수 있습니다. 비밀번호 등 개인 정보는 선택하지 마세요. 잠금 상태의 표시는 기기의 개인정보 설정을 따릅니다.

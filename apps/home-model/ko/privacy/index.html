개인정보 처리방침

최종 업데이트: 2026-10-04

계정이 필요 없어요. 사진과 기록은 앱에 저장되며 앱이 외부로 업로드하지 않아요. 앱을 삭제하면 기록도 삭제돼요. 클라우드 동기화와 데이터 이전 기능은 없어요.

1. 운영자와 적용 범위

DOTNULL Co.,Ltd는 이 앱과 소개·지원 사이트의 정보를 본 방침에 따라 처리합니다.

2. 기록의 저장과 사용

사진, 입력값, 메모, 평가(해당 앱), 초안, 작성·수정 시간을 표시·검색·편집·미완성 입력 복원을 위해 기기에 저장합니다. 사진은 앱 저장 공간으로 복사합니다. 사진과 기록 내용은 광고 요청에 포함하지 않습니다.

3. 사진 인식

Google ML Kit로 문자와 바코드를 기기에서 인식합니다. 이미지와 인식 결과는 기기 안에서 처리합니다. ML Kit는 업데이트·호환성·유지·개선·부정 사용 방지를 위해 Google과 통신하며 사용 현황·성능·진단 정보를 보낼 수 있습니다.

4. 카메라와 사진 권한

촬영과 사용자가 선택한 이미지 가져오기에 카메라·사진 선택 기능을 사용합니다. 필요한 권한은 OS에 따라 확인하며 기기 설정에서 변경할 수 있습니다. 허용하지 않아도 직접 입력과 저장된 기록 보기는 가능합니다.

5. 광고와 동의

Google Mobile Ads와 UMP는 광고 제공·측정, 진단, 부정 방지, 동의 관리를 위해 IP 주소(대략적인 위치 추정에 사용될 수 있음), 기기 식별자, 광고 표시·조작, 앱 조작, 성능·진단 정보, 동의 선택을 처리할 수 있습니다. 비개인화 광고를 요청해도 정보 처리가 없어지지는 않습니다. 필요한 지역에서 동의 화면을 표시하고, 필요한 경우 앱 정보에서 광고 개인정보 설정을 열 수 있습니다. iOS 추적 권한은 요청하지 않습니다. 광고 동의나 제공 여부와 관계없이 기록 기능을 이용할 수 있습니다.

6. 보관·삭제·백업

기록은 삭제할 때까지 보관합니다. 앱에서 기록·사진·초안을 삭제할 수 있습니다. 다른 기록이 참조하는 사진은 참조가 없어질 때까지 남습니다. 앱 삭제나 기기 데이터 초기화로 기록을 잃을 수 있습니다. 자체 클라우드 동기화·백업·내보내기·기기 이전 기능은 없습니다. OS나 기기의 이전·복원은 보장하지 않습니다. Android 표준 백업은 비활성화되어 있습니다. 앱에서 삭제해도 기존 OS 백업이나 Google이 처리한 정보는 삭제되지 않습니다.

7. 사이트와 외부 서비스

사이트에는 자체 분석 도구나 광고가 없습니다. GitHub Pages로 제공하며 GitHub가 IP 주소 등 접근 정보를 처리할 수 있습니다. 외부 사이트에는 각 제공자의 방침이 적용됩니다.

8. 문의와 정보 관리

문의에 제공한 이름·이메일·내용·선택적 첨부는 답변·조사·지원 기록 관리에 사용합니다. 지속적인 지원이나 법적 보관 의무를 제외하고 불필요해진 정보는 삭제합니다. 필요한 담당자만 접근하며 이메일·보관 서비스에 필요한 위탁이나 법률상 허용되는 경우 외에는 동의 없이 제삼자에게 제공하지 않습니다. 이용 목적 안내·열람·정정·삭제·처리 제한 요청은 문의 창구로 보내 주세요. 본인 확인 후 관련 법에 따라 대응합니다. 기기에만 있는 기록은 당사가 열람·변경할 수 없습니다. Google과 GitHub의 처리에는 각사 방침이 적용됩니다.

9. 변경과 연락처

방침이 바뀌면 내용과 업데이트 날짜를 갱신하며 중요한 변경은 앱이나 사이트에서 알립니다.

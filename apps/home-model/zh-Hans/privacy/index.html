1. 运营者及适用范围

DOTNULL Co.,Ltd 按照本政策处理本应用及介绍、支持网站中的信息。

2. 记录的保存和使用

照片、填写内容、备注、评价（支持该功能的应用）、草稿、创建和更新时间保存在设备内，用于显示、搜索、编辑及恢复未完成的输入。照片会复制到应用存储空间。照片和记录内容不会包含在广告请求中。

3. 照片识别

使用 Google ML Kit 在设备上识别文字和条形码。图像和识别结果在本地处理。ML Kit 可能为更新、兼容性、维护、改进和防止滥用而与 Google 通信，发送使用情况、性能和诊断信息。

4. 相机和照片权限

相机和照片选择功能用于拍摄或导入您选择的照片。所需权限因系统而异，可在设备设置中更改。不授权仍可手动输入或查看已保存的记录。

5. 广告及同意

Google Mobile Ads 和 UMP 可能处理 IP 地址（可能用于推测大致位置）、设备标识符、广告展示及互动、应用互动、性能及诊断信息、同意选择，用于广告投放和衡量、诊断、防欺诈及同意管理。我们请求非个性化广告，但这不代表不处理信息。必要地区会显示同意界面，需要时可在关于应用中打开广告隐私设置。不请求 iOS 跟踪许可。无论广告同意或投放情况如何，均可使用记录功能。

6. 保存期限、删除和备份

记录保存至您删除为止。可在应用内删除记录、照片和草稿。被其他记录引用的照片会保留至不再被引用。卸载应用或清除设备数据可能导致记录丢失。不提供自有云同步、备份、导出或设备迁移功能，不保证系统或设备的迁移及恢复。Android 标准备份已禁用。应用内删除不会删除已有系统备份或 Google 已处理的信息。

7. 网站及外部服务

网站不设自有访问分析或广告。使用 GitHub Pages 托管，GitHub 可能处理 IP 地址等访问信息。外部网站适用各提供者的政策。

8. 咨询及信息管理

咨询中提供的姓名、邮箱、正文及可选附件用于回复、调查及管理支持记录。除持续支持或法律要求的保存期限外，不再需要的信息会删除。访问限于必要人员，除必要邮件及存储服务委托或法律允许的情况外，不未经同意向第三方提供。可联系我们申请说明用途、访问、更正、删除或限制处理，经核实身份后依法处理。我们无法访问或修改仅在设备中的记录。Google 和 GitHub 的处理适用各自政策。

9. 变更及联系方式

政策变更时会更新内容和日期，重大变更会通过应用或网站告知。

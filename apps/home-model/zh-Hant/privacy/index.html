隱私權政策

最後更新: 2026-10-04

無需帳號。照片和紀錄儲存在應用程式內，應用程式不會上傳這些內容。刪除應用程式也會刪除紀錄。不支援雲端同步或資料移轉。

1. 營運者與適用範圍

DOTNULL Co.,Ltd 依照本政策處理本應用程式及介紹、支援網站中的資訊。

2. 紀錄的儲存與使用

照片、填寫內容、備註、評價（支援該功能的應用程式）、草稿、建立與更新時間儲存在裝置內，用於顯示、搜尋、編輯及復原未完成的輸入。照片會複製到應用程式儲存空間。照片與紀錄內容不會包含在廣告請求中。

3. 照片辨識

使用 Google ML Kit 在裝置上辨識文字和條碼。影像與辨識結果在本機處理。ML Kit 可能為更新、相容性、維護、改進和防止濫用而與 Google 通訊，傳送使用情況、效能與診斷資訊。

4. 相機與照片權限

相機與照片選擇功能用於拍攝或匯入您選擇的照片。所需權限因系統而異，可在裝置設定中變更。不授權仍可手動輸入或查看已儲存的紀錄。

5. 廣告與同意

Google Mobile Ads 和 UMP 可能處理 IP 位址（可能用於推測概略位置）、裝置識別碼、廣告顯示與互動、應用程式互動、效能與診斷資訊、同意選擇，用於廣告投放及衡量、診斷、防詐欺及同意管理。我們要求非個人化廣告，但這不代表不處理資訊。必要地區會顯示同意畫面，需要時可在關於應用程式中開啟廣告隱私設定。不要求 iOS 追蹤許可。不論廣告同意或投放情況如何，都能使用紀錄功能。

6. 保存期限、刪除與備份

紀錄保存至您刪除為止。可在應用程式內刪除紀錄、照片及草稿。被其他紀錄引用的照片會保留至不再被引用。移除應用程式或清除裝置資料可能導致紀錄遺失。不提供自有雲端同步、備份、匯出或裝置移轉功能，不保證系統或裝置的移轉與復原。Android 標準備份已停用。應用程式內刪除不會刪除既有系統備份或 Google 已處理的資訊。

7. 網站與外部服務

網站不設自有存取分析或廣告。使用 GitHub Pages 託管，GitHub 可能處理 IP 位址等存取資訊。外部網站適用各提供者的政策。

8. 諮詢與資訊管理

諮詢中提供的姓名、電子郵件、正文及選填附件用於回覆、調查及管理支援紀錄。除持續支援或法律要求的保存期限外，不再需要的資訊會刪除。存取限於必要人員，除必要郵件及儲存服務委託或法律允許的情況外，不會未經同意向第三方提供。可聯絡我們申請說明用途、存取、更正、刪除或限制處理，經核實身分後依法處理。我們無法存取或修改僅在裝置中的紀錄。Google 和 GitHub 的處理適用各自政策。

9. 變更與聯絡方式

政策變更時會更新內容和日期，重大變更會透過應用程式或網站告知。

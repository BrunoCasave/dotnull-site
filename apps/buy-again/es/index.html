Funciones

Tu última compra te ayuda a elegir.

Un producto guardado con el mismo código muestra su valoración anterior. Las sugerencias vienen del envase, no de una base de productos en línea.

  • Lee el envase para sugerir nombre, marca y cantidad
  • Valora con Lo compraría, Quizás o No repetiría
  • Guarda nombre, cantidad, código de barras, notas y varias fotos
  • Busca productos o notas y filtra por valoración
  • Consulta la valoración de un producto guardado mediante su código
  • Crea categorías y filtra productos por categoría o valoración.
  • Se muestra un banner de Google AdMob abajo. El SDK envía a Google datos del dispositivo para los anuncios. No añadimos fotos, modelos, productos, valoraciones ni notas a las solicitudes.

Tus notas quedan en el dispositivo.

No necesitas cuenta. Las fotos y notas se guardan en la app y no se suben desde ella. Al borrar la app se borran las notas. No hay sincronización ni transferencia de datos.

Google ML Kit también puede enviar datos de uso, rendimiento y diagnóstico a Google. Consulta la política de privacidad. Puedes usar las notas sin consentimiento publicitario ni conexión.

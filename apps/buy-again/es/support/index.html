Ayuda

¿Cómo añado un registro?

Elige Añadir una foto, toma o selecciona una imagen, revisa y corrige las sugerencias, y guarda. También puedes escribir a mano.

El texto no se reconoce bien

Usa buena luz, acerca el texto y reduce reflejos e inclinación. Puedes corregir las sugerencias o guardar solo la foto.

¿Cómo edito o borro?

Abre el registro y pulsa Editar para cambiar campos y fotos. Los registros borrados no se pueden restaurar.

¿Y si cambio de dispositivo o desinstalo?

No hay sincronización, copia ni migración propias. Guarda la información importante aparte. No se garantiza el traslado mediante el sistema o dispositivo.

¿Dónde están los ajustes de anuncios?

Se muestra el consentimiento donde sea necesario. Las opciones de privacidad publicitaria aparecen en Acerca de la app cuando se requiere cambiar la elección. Los registros funcionan sin anuncios.

Las fotos ayudan a escribir.

Un producto guardado con el mismo código muestra su valoración anterior. Las sugerencias vienen del envase, no de una base de productos en línea.

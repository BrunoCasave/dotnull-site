개인정보 처리방침

최종 수정: 2026년 10월 18일

현재 개발 중인 시험 버전에 관한 안내입니다. 정식 버전의 기능·광고·요금은 출시 전에 안내합니다.

1. 운영자

DOTNULL Co.,Ltd가 스마트폰 휴식과 본 사이트를 운영합니다. 문의: phonebreak@dotnull.co.jp.

2. 기기 내 정보

설정과 알림 시점을 판단하는 데 필요한 사용 상태는 기기 안에서 처리합니다. iPhone은 선택한 항목의 스크린 타임 토큰도 저장합니다. Android의 현재 사용 시간은 서비스 메모리에서 관리하며 프로세스 종료 후 복원하지 않습니다. 화면 내용, 입력한 문자, 메시지를 읽지 않습니다. 사용 기록과 선택 토큰을 당사 서버, 광고 요청 또는 GitHub로 전송하지 않습니다. 계정, 자체 분석 도구, 클라우드 동기화는 없습니다.

3. 개발 버전의 테스트 광고

Google Mobile Ads SDK로 공식 테스트 배너를 표시합니다. 광고 요청 시 Google과 통신하며 IP 주소, 기기·앱 식별 정보, 광고 상호작용과 진단 정보 등이 처리될 수 있습니다. 모든 정보가 기기 내에만 머무는 것은 아닙니다. 현재 Android 광고 ID 권한은 제외하며 iOS ATT 권한을 요청하지 않습니다. 정식 빌드의 광고 전송은 비활성화되어 있습니다. 실제 광고를 도입하기 전에 필요한 고지와 동의 절차를 마련합니다. 국외 처리 등은 아래 Google 정책도 확인해 주세요.

4. 사이트와 이메일

이 페이지에 당사 분석 도구나 광고 추적기를 넣지 않습니다. 호스팅 업체 GitHub는 사이트 제공·보호를 위해 IP 주소 등의 접속 정보를 처리합니다. 문의 이메일의 이름, 주소, 내용은 답변과 문제 해결에 사용합니다. 개인 사용 기록이 이메일에 자동 첨부되지는 않습니다.

5. 보관·삭제·권리

앱 삭제 등으로 기기 내 설정을 삭제할 수 있습니다. OS 백업과 스크린 타임 공유는 OS 설정에서 관리하세요. 문의 정보는 대응 또는 법적 의무에 필요한 기간만 보관하며 접근을 제한하고 불필요해지면 삭제합니다. 열람·정정·삭제 요청은 문의처로 연락하세요. 기기 밖으로 전송되지 않은 사용 기록은 당사가 열람하거나 원격 삭제할 수 없습니다.

6. 변경

처리 방식이 바뀌면 이 페이지와 수정일을 갱신합니다. 새로운 이용 목적이나 광고에 별도 고지·동의가 필요하면 해당 절차를 진행합니다.

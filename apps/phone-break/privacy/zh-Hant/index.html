隱私權政策

更新日期：2026年10月18日

此處說明適用於開發中的試用版本。正式版功能、廣告與費用將於發布前說明。

1. 營運者

手機休息與本網站由 DOTNULL Co.,Ltd 營運。聯絡信箱：phonebreak@dotnull.co.jp。

2. 裝置內的資訊

監測設定及判斷提醒時間所需的使用狀態在裝置內處理。iPhone 另儲存所選項目的螢幕使用時間權杖。Android 目前使用時間存放於服務記憶體，程序結束後不會還原。本 App 不讀取畫面內容、輸入文字或訊息。使用記錄與選取權杖不會傳送至我們的伺服器、廣告請求或 GitHub。沒有帳號系統、自建分析或雲端同步。

3. 開發版測試廣告

開發版使用 Google Mobile Ads SDK 顯示官方測試橫幅。廣告請求會連線至 Google，可能涉及 IP 位址、裝置或 App 識別資訊、廣告互動及診斷資訊，並非所有資訊都只留在本機。目前 Android 已排除廣告 ID 權限，iOS 不要求 ATT 權限。正式建置的廣告投放已停用。導入正式廣告前會提供必要揭露與同意管理。Google 的處理及境外處理請參閱下方政策。

4. 網站與電子郵件

此頁面不加入我們自己的分析或廣告追蹤工具。託管業者 GitHub 為提供及保護網站，處理 IP 位址等存取資訊。來信中的姓名、信箱及內容用於回覆與處理問題，不會自動附上個人使用記錄。

5. 保存、刪除與權利

刪除 App 等操作可移除本機設定。系統備份與螢幕使用時間共享請透過系統設定管理。詢問資訊僅在處理問題或履行法律義務所需期間保存，限制存取，並在不再需要時刪除。如需查詢、更正或刪除，請與我們聯絡。未傳出裝置的使用記錄無法由我們檢視或遠端刪除。

6. 變更

處理方式改變時會更新本頁面與日期。新的用途或廣告如須另外通知或取得同意，將依規定辦理。
